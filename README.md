## 📖 About

This repository holds my **Data Structures** work for the **Marvellous Logic Building Batch** — implementing every structure from scratch instead of using library versions, so the mechanics stay clear: linked lists (singly, doubly, circular), stacks, queues, trees, graphs, sorting, and searching.

Programs are added here assignment by assignment, in batch order, as the Data Structures stage progresses — each one compiled and tested before it is committed.

---

## 🗂️ Structure

```text
Data_Structures/
│
├── README.md
├── LICENSE
├── .gitignore
├── assets/                 ← banner & footer artwork used in this README
│
├── Assignments/
│   ├── Assignment_1/       ← 5 solutions per assignment
│   ├── Assignment_2/
│   └── …
│
└── Classwork/
    └── Day_NN/             ← classwork, added as the batch progresses
```

- **5 programs per assignment**, one folder per assignment: `Assignments/Assignment_N/`

## ▶️ How to Compile & Run

```bash
gcc program1_1.c -o program1_1
./program1_1
```
